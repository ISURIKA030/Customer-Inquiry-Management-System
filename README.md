# Customer Inquiry Management Sytem

A full-stack web application developed for the Coffree Ninja full-stack Developer Interntechnical assessment.

# Technology Stack

- Frontend : React
- Backend : Node.js and Express.js
- Database : PostgreSQL

# Core Features

- Secure staff Authenitaction
- Create customer inquiries
- Search and filter inquiries
- Track inquiry status
- Dashboard with inquiry summaries

# Project Structure

- frontend/ - React application
- backend/ - Express API
- database/ - Database schema and setup scripts
